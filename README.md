# Death-Education-Data

De-identified participant-level data, analysis code, and figures for two school-based studies of death-related narrative and reflection, delay discounting, temporal resource allocation, and subjective time among children and adolescents in Shanghai, China.

## Repository contents

- `data/`: analysis-ready public datasets for Study 1 (`N = 250`) and Study 2 (`N = 190`).
- `metadata/`: variable definitions, coding rules, analysis roles, and missing-value counts.
- `code/`: independently runnable Study 1 and Study 2 analyses plus combined figure generation.
- `results/`: machine-readable statistical results generated by the analysis scripts.
- `figures/main/`: the three principal figures in PNG and vector PDF formats.
- `tests/`: executable checks for the reported statistics and figure outputs.
- `docs/`: notes on de-identification and data preparation.

CSV is the canonical machine-readable format used by the analysis scripts.

## Data protection

The public datasets exclude school names, original student identifiers, source row numbers, questionnaire names, free-text responses, and variables not required for the reported analyses. Public participant IDs were generated independently, rows were randomly reordered, and no public-to-source linkage table is included. The research team has confirmed authorization for public release of these de-identified materials.

## Scoring and coding

- `ln_k_pre` and `ln_k_post` are natural-log-transformed delay-discounting parameters. Larger values indicate steeper delay discounting.
- Temporal allocations are percentages assigned to immediate, short-term, and long-term horizons.
- Subjective-time scores are three-item means on a `0-100` metric.
- Study 2 purpose responses use five English categories. Implementation-intention responses use `1 = unlikely`, `2 = possible`, and `3 = very_likely`.
- Blank cells represent missing values. Study 1 has 11 missing exact-age values; other retained fields are complete.

## Reproduce the analyses

Use R 4.4 or later. Install the required packages once:

```r
install.packages(c("readr", "dplyr", "tidyr", "purrr"))
```

From the repository root, run:

```bash
Rscript code/study1_analysis.R
Rscript code/study2_analysis.R
Rscript code/figure_generation.R
```

The scripts use repository-relative paths and read only the de-identified CSV files included here.

## Verify the outputs

```bash
Rscript tests/test_study1_analysis.R
Rscript tests/test_study2_analysis.R
Rscript tests/test_figure_generation.R
```

See `code/README.md` for the analyses and output files produced by each script.
