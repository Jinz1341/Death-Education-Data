# Public data preparation

## Study 1

The public analytic file contains 230 participants with complete pretest and posttest outcome data. The Grade 4 cohort includes observed ages 9–10 (*n* = 104). The Grade 8 cohort is retained in full (*n* = 126); age is observed for 117 participants and ranges from 13 to 16.

Direct identifiers are not included. `participant_id` is an anonymous study-specific identifier. The three allocation percentages sum to 100 at each assessment time point.

## Study 2

The participant-level file contains 184 participants aged 10–16 with complete analysis variables. The item-level file contains one record for every participant, assessment time point, and intertemporal-choice item: 184 participants × 2 assessment time points × 7 items = 2,576 rows.

The participant-level and item-level files share anonymous participant IDs. Item-level SS/LL choices, stated purposes, and implementation-intention ratings agree with the corresponding participant-level questionnaire fields.

## Variable definitions

Complete names, encodings, ranges, and analysis roles are listed in `metadata/public_data_dictionary.csv`.
